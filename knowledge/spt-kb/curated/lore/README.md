# EFT 世界观与背景知识（lore 分区）

> 状态：2026-08-16 建立（10 文件完成） | 版本标签：[通用]（世界观跨 SPT 版本有效）
> 用途：整合包玩家背景阅读 + mod 开发世界观一致性参考

## 分区说明

本分区存放《逃离塔科夫》（Escape from Tarkov）的故事、背景、世界观知识——区别于本 KB 其他分区的 modding 技术内容。内容为**提炼性质**（非全文搬运），provenance 逐文档标注；详细原始资料见 `../../sources/third-party.md` 登记的外部来源。

## 阅读顺序

1. **`01-world-overview.md`** — 世界观总览：Norvinsk SEZ、冲突起因、Russia-2028 宇宙、Contract Wars 前传
2. **`02-timeline.md`** — 时间线：世界线、主线章节顺序、删档赛季表、版本演化
3. **`03-factions.md`** — 派系志：USEC/BEAR/Scavs/Rogues/Cultists/UNTAR/Black Division + 关系图
4. **`04-terragroup.md`** — TerraGroup 集团与阴谋主线（净化、无名者、罪证链）
5. **`05-locations.md`** — 13 张地图设定（地理、控制方、Boss、剧情意义）
6. **`06-traders.md`** — 商人志：11 位商人背景与立场
7. **`07-story-chapters.md`** — 主线剧情章节（Tour → Boreas → 门票四结局 + 破冰船线）
8. **`08-glossary.md`** — 术语表（机制 + 世界观术语对照）
9. **`09-game-history.md`** — 游戏史：开发、发布、删档、地图版本线
10. **`10-map-landmarks.md`** — 地图地标方位参考（12 图内部地标/Boss 领地/撤离点方位，以玩家地图实测为基准）
11. **`11-trader-questlines.md`** — 商人支线任务线梳理（按商人的叙事主题线 + 跨商人链）
12. **`12-map-relations.md`** — 地图间地理关系（图间通路、整体布局、商人据点标注，社区合成图口径）
