# 塔科夫游戏史

> 状态：2026-08-16 提炼 | 版本标签：[通用]
> 来源：Wikipedia、eftarkov.com（删档历史）

## 开发历程

- **2012**：Battlestate Games 启动开发；首席开发 Nikita Buyanov 与团队经验来自 Absolutsoft 的前作《Contract Wars》。
- **Russia-2028 宇宙**：本作与 Contract Wars/Hired Ops 共享世界观。
- 团队含真实军事背景成员（一名前 Spetsnaz 特种部队成员）；武器音效在废弃仓库用真枪实弹录制。
- 引擎：Unity。

## 发布里程碑

| 时间 | 事件 |
|------|------|
| 2016-08-04 | 封闭 alpha（预购玩家，NDA 约束） |
| 2016-12-28 | 扩展 alpha（更多预购档位开放） |
| 2017-03-24 | NDA 解除，视频内容解禁 |
| 2017-07-28 | 封闭 beta（0.4 起，删档赛季制开始） |
| 2020 初 | Twitch 促销引爆人气；2020-05 峰值 20 万并发 |
| 2023 | 发布独立竞技模式 EFT: Arena（含战斗通行证） |
| 2025-04-10 | Arena 登陆 Epic Games Store |
| 2025-08-20 | 补丁 0.16.9.0：加入 "Friend from Norvinsk" 任务线；藏身处小游戏 TarGrad Tales 内藏 QR 码预告 1.0 日期 |
| **2025-11-15** | **1.0 正式版发布**（Steam 同步），主线章节系统完整 |

## 版本结构

- 四个版本档位：Standard / Left Behind / Prepare for Escape / Unheard Edition。
- 模式：PVP（删档赛季）、PVE（无删档）、Arena（竞技场）。

## 删档与赛季（摘要）

- PVP 自 0.4.0（2017-10-27）起周期性删档，赛季周期约 60-237 天（平均约 6 个月）；当前 1.0.0.1 赛季自 2025-11-15 进行中。
- PVE 自 0.14.6.0（2024-04-25）起永不删档。
- 1.0 时代加入赛季服（17 个赛季专属任务）与 BattlePass（8 类文档收集）。
- 完整赛季表见 `02-timeline.md`。

## 对 SPT 环境的意义

- SPT 4.1 对应 EFT 0.16.9.5.40743（1.0 时代客户端，2026-08 核实），因此本史表中的 1.0 内容（章节系统、赛季/BattlePass、迷宫/破冰船/码头）在 SPT 中全部可用。
- 游戏史是整合包发版说明与玩家手册的背景素材（"从 0.4 到 1.0，塔科夫经历了 X"）。
