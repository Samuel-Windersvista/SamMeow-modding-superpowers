# 塔科夫地图间地理关系 [通用]

> 状态：2026-09-03 提炼 | 版本标签：[通用]
> 来源：玩家自拼合成图（NICK'S OPEN WORLD V5.x，含中文二次标注）+ 各单图玩家地图（转场点标注交叉验证）
> 性质说明：**社区合成图，非官方设定**——是玩家社群对塔科夫各地图真实地理关系的共识表达；各图内部地标以 `10-map-landmarks.md` 为准，本文件专记图与图之间的关系。

## 一、整体布局（上北下南）

```
                        [LA 实验室](北部城区地下)
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
   |  海(西北)      (Equator)     (The Lab*)   [GZ 中心区]|
   |                    \          北部城区     |   |
   |   (Town,未开放)    [W 森林]==[F 工厂] [ST 街区]--+   |
   |                     ||   //    |            |
   |                     ||  // 前往立交桥        |
   |   [L 灯塔]          [C 海关(横长)]==[I 立交桥]  |
   |   (西海岸竖条)       |  \    (Suburbs,未开放)  |
   |     |付费路→R       [R 储备站] \             |
   |     |               |    \                  |
   |     +---南部大路---[S 海岸线(最大)]           |
   |   海(西南)           |         \虚线   [T 码头]|
   |                     码头Pier     (Airport)码头|
   ~~~~~~~~~~~~~~~~~海(南岸)~~~~~~~~~~~~~~~~~~~~~~
```

**要点**：
- **城区集中在北—东北**：中心区 GZ（东北）、街区 ST（中偏东北）、实验室 LA（北部城区地下）
- **野外/郊区在西—南**：森林 W（西中）、工厂 F（中西部）、海关 C（中部横长）、立交桥 I（中东部）、储备站 R（中南部偏西）、海岸线 S（南部最大）、灯塔 L（西海岸竖长条）、码头 T（东南角）
- **海在西侧与南侧**（芬兰湾弧形海岸线）：靠海图 = 灯塔（西海岸）、海岸线（南）、码头（南岸）、Town（西北近海，未开放）
- 未开放/底图 POI：Equator（西北城区）、Town（西侧近海，锁）、Suburbs（中东部，锁）、Airport（东南内陆）

## 五、写作与 mod 用途

- 写小说跨图旅行时：内陆图之间步行可达（森林→工厂→海关→立交桥→街区形成主链），海边图（海岸线/灯塔/码头）沿南岸-西岸分布
- 开放世界类整合包/mod：合成图是玩家共识的地理模型，可作"跨图联通"mod 的参照
- 转场机制（1.0 Transit）的图间通路与上表一致，单图内的转场点坐标见 `10-map-landmarks.md`
