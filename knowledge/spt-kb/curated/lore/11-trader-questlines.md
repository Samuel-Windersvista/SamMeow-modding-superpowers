# 商人支线任务线梳理 [通用]

> 状态：2026-09-03 提炼 | 版本标签：[通用]
> 数据源：live 快照 `tasks.json`（517 任务，含前置链 taskRequirements）+ `tasks_zh.json`（中文名）+ SPT `database/templates/quests.json`（558 任务，QuestName 为英文原名）；商人背景见 `06-traders.md`
> 用途：把散装任务清单重组成"叙事主题线"，供写小说（角色成长弧线素材）与写 mod（任务链设计模板）直接取用
> 命名说明：live 与 SPT 存在命名/编号差异，已在文中如实标注（最典型：The Punisher 系列 live 1.0 重编号）。跨源引用任务时**按 id 对齐，勿按"Part n / 第 n 部"序数对齐**。

## 0. 总览：谁在给谁讲故事

塔科夫的任务体系不是 517 个孤岛，而是十一套商人视角的"角色小传"。归纳如下：

| 商人 | 核心母题 | 代表主线（live 编号/中文） |
|---|---|---|
| Prapor | 老兵还乡：复仇 + 补给 | The Punisher（惩罚者 1-6） |
| Therapist | 医者仁心：救命 + 查案 | 医疗隐私 1-6 |
| Skier | 走私起家：脏钱 + 人脉 | Chemical 1-4（化学品） |
| Mechanic | 匠人执念：修枪 + 修天线 | Gunsmith / 枪匠大师 + 灯塔接触线 |
| Jaeger | 荒野法则：猎杀 + 求生 | The Huntsman Path（猎人之路） |
| Peacekeeper | 冷战棋子：维和 + 情报 | Wet Job（湿活 1-6） |
| Ragman | 废墟商业：布匹 + 物流 | 新起点 系列 + 42 级大后期组 |
| Fence | 混沌中立：赎罪 + 收藏 | 建立联系→…→抉择（终极任务） |
| Lightkeeper | 隐士棋手：网络 + 预言 | 情报之源→…→大都会之谜（岛内十步） |
| BTR 司机 | 车轮帝国：破冰船四支线 | 坚持到底→…→宿醉 等四条 |
| 竞技场裁判 | 表演与赌局（PVP 层） | 再创新高 1-6 等 |

> 本文档按"主题线"叙事，不代表每线都可独立接取——多数线共享商人声望/等级门槛，接取顺序仍以游戏内前置为准。代表任务中文名取自 `tasks_zh.json`；英文名取自 wikiLink/SPT QuestName，首次出现标注。

## 1. Prapor（普拉波尔）—— 66 个任务

Prapor 是苏军老军需官、BEAR 老兵网的核心接头人，满口"为了祖国"的旧式军人腔。他的任务网主题集中在三件事：**对背叛者的清算、对旧军需的执念、对"往事"的挖掘**。任务链上的等级分水岭非常清晰：L12-17 一段（往昔时光环）、L36 一段（惩罚者终段 + 出警）、L46（护送）。

### 1.1 新兵差事线（前期 0-15 级）
从"首秀"开始，Prapor 把你当新兵使唤：递口信、清据点、取证物，全是最朴素的跑腿+清剿组合。
- 代表任务：首秀、背景调查、罪证、探囊取物、硝烟野餐、打靶训练（L1）、麻醉
- 目标类型：击杀（PMC/Scav 指定数量）、上交物品、访问区域——教学性质，全是"去哪、杀谁、带什么回来"

### 1.2 猎杀线 The Punisher（惩罚者 1-6，中期 21-36 级为轴）
Prapor 对"背叛者/敌对 PMC"的猎杀令，全游戏最硬核的 PvP/PvE 击杀链之一。任务名直白：惩罚。逐部加码——从"穿指定装备杀 PMC"到"用特定武器清 Scav 营地"，最后以"出警-商场 / 出警-检票"收尾（两任务在 36 级档，惩罚者 6 的前后呼应）。
- 代表任务：惩罚者 - 1 → 惩罚者 - 2 → 惩罚者 - 3 → 惩罚者 - 4 → 惩罚者 - 5 → 惩罚者 - 6，接 出警 - 商场 → 出警 - 检票
- ⚠️ 编号差异（重编号）：live 快照把同批 id 按新顺序编号为「惩罚者 - 1~6」（惩罚者-1=`59c512ad`）；SPT QuestName 中同一 id 叫 `The Punisher - Part 3`（`59c50a9e`=Part 1、`59c50c88`=Part 2，4-6 相同）。即 1.0 把前 3 部顺序轮换重排——跨源引用勿按序数对齐，以 id 为准。
- 目标类型：击杀（着装/武器/距离限定）、特定 Boss、撤离
- 剧情意义：惩罚者 - 6 是 Fence 终极任务「抉择」（433,333 经验）的前置——整条猎杀线最终通向"算总账"的哲学时刻

### 1.3 邮包与军需补给线（全期散布）
老军需官的本行：油料、弹药、苏制装备、旧信件。任务多半是"送/找军用物资"，串起他与 BTR 司机（货运延误）和 Therapist（邮递员派特）的合作。
- 代表任务：油料交换 / 油料快车、塔市进口货、多鱼之漏、往事速递、邮递员派特 - 1（→ Therapist 的 -2）、货运延误 - 1（→ BTR 风火轮线）
- 目标类型：上交物资、放置标记、送信（place/mark + extract）

### 1.4 老兵岁月环（Boreas 时代的跨商人回忆群，L12 起）
live 1.0 前后新增的一簇"回忆/记录"题材任务，Prapor 是发起点：往昔时光 - 1/-2 引出 人间地狱 1-2（Prapor 侧）与一串跨商人接力——质量标准（→Therapist）、高光时刻（→Skier）、忠实观众与严词指控（Skier 侧接回）、镜头就位，开拍！（→Mechanic，12 目标）。叙事上是"追忆战地往事"的群像戏。
- 代表任务：往昔时光 - 1 → 往昔时光 - 2、人间地狱 - 1 → 人间地狱 - 2、忠实观众（→严词指控）
- 目标类型：找证据/记录物、击杀、上交；多图往返

### 1.5 大后期武力展示（35 级后）
管制材料、透透气、艺术就是爆炸（36 级 65k 经验三连）与 **护送**（46 级 155k 经验，全商人单体经验最高档之一）——Prapor 在终局把你当"老兵"托付最重的活。
- 目标类型：高价值清剿/护送/长时间生存

## 2. Therapist（治疗师）—— 52 个任务

塔科夫地下诊所的医生，明面上救死扶伤、暗地里用医疗网收集全城情报。她的任务是全游戏"人道主义底色"最重的：**救人和查人两条线交替推进**，主线是散落全期的「医疗隐私」系列（6 部，从 L0 一路到 L37）。

### 2.1 医疗主线：医疗隐私 1-6（贯穿全期）
从"去诊所取病历"起步，逐步挖出某位神秘病人的隐私、牵扯出地下医疗黑幕（医疗隐私 - 4 之后扇出 运动员 / 私人诊所 / 一天一个苹果 等多条支线）。
- 代表任务：医疗隐私 - 1 → -2 → -3 → -4 → -5 → -6（L0→L37）
- 支线：运动员（L30）、私人诊所（L35）、一天一个苹果 - 医生远离我
- 目标类型：取病历/物品、访问医疗点、上交药物、击杀"知情者"

### 2.2 人道救援线（前期主力，0-15 级）
短缺、药剂师、救助站点、带血的水、水瓶座行动、卫生标准 1-2、善良之针——塔科夫最常见的"市民缺药缺水"叙事，任务目标几乎全是**收集医疗/饮用水物资**交给她分发给平民。
- 代表任务：短缺、带血的水、药剂师、救助站点（8 目标大任务）、水瓶座行动、供给计划 → 危险之路（L15）
- 目标类型：findItem/giveItem（战局内获取医疗品）、击杀污染源

### 2.3 失踪与地下调查线（中期 18 级后）
Therapist 的"情报网"属性浮现：消失的线人、同事、刨根问底、街区之下（L37）、灭虫服务（L37）——从找人到清剿街区地下的"虫害"（某组织）。
- 代表任务：消失的线人、同事、街区之下、灭虫服务
- 目标类型：找线人遗物（findQuestItem + possibleLocations）、击杀指定目标

### 2.4 战争创伤新叙事（live 1.0 新增群，0 级起散布）
生化分析、战争从未改变、无主货物、货运追踪、平易近人、兽医也是医 1-2、塔科夫屠夫、急单（38 级）——这批 2025-2026 新增任务把 Therapist 的戏份从"诊所医生"推向"战地伦理观察者"（尸体、毒物、屠宰、急单抢救）。
- 目标类型：验尸/采样（findQuestItem）、上交战地物资、带伤生存

### 2.5 跨商人接线（见 §12）
出于好奇（须 Skier 化学品 - 4）、质量标准（须 Prapor 往昔时光 - 1）、这带子糟透了（须 Mechanic 武装侦察）——Therapist 是任务网里最常被"借调"的收尾人。

## 3. Skier（滑雪者）—— 66 个任务

海关区发迹的年轻奸商，自称"什么都能搞到"。他的任务主题是**钱与人脉**：早期（化学品 1-4）是亡命走私的回忆录，中期（供应商/软禁）是讨债与供货的日常，后期（公道价/L50 组）是把自己洗成"正当商人"的野心戏。

### 3.1 走私线 Chemical 1-4（前期 0-9 级，主线中的主线）
Skier 的成名作：一桩化学品的走私烂账，从海关的 Polikhim 化工厂废墟里翻证据、跟线、灭口。完成后大幅扇出：大客户（→Prapor）、出于好奇（→Therapist）、收买人心——是前期最重要的跨商人枢纽链。
- 代表任务：化学品 - 1 → 化学品 - 2 → 化学品 - 3 → 化学品 - 4（英文 Chemical - Part 1~4）
- 目标类型：findQuestItem（化工厂证物）、击杀、上交
- 剧情意义：化学品 - 3 是 Fence「收藏家」的五大前置之一

### 3.2 灰色交易/讨债线（前期至中期）
供应商（Supplier）、金色失物、U盘里有什么？、情报就是力量、敲诈者、维他命、供货、Polikhim流浪汉——"回收"与"赖账"主题；中期的 软禁 → 软禁 - 2（L33）是这条线的长尾。
- 代表任务：供应商、金色失物、敲诈者、维他命、软禁、软禁 - 2
- 目标类型：找贵重物（U 盘/金链）、上交、击杀目标、放置"警告"

### 3.3 西化装备线
西方来客（Friend From the West）1-2、转口贸易——Skier 替 Peacekeeper/西方客户办"进口"差事，顺手把西式武器引进黑市。西方来客 - 2 在任务网里是早期解锁更多商人对话的常见节点。
- 目标类型：上交西式装备/击杀 USEC 目标

### 3.4 人脉扩张与"洗白"线（1.0 新任务群 + 50 级终局）
识时务者为俊杰、关键伙伴、致命论据、后知后觉、偏离路线、一报还一报（L12）——"选对朋友"主题；大后期 42-50 级组则是一整段"生意帝国"戏：公道价 1-2（须 Mechanic 同好俱乐部）、有利可图的生意 → 学无止境 → 站稳脚跟、安全保障 → 人生之课 → 利润保留。绝对威信（L26）挂在 Mechanic「武装侦察」之后。
- 代表任务：一报还一报、公道价 - 1/-2、绝对威信、学无止境、站稳脚跟、人生之课
- 目标类型：交"学费"（现金/货物）、清场、商会式互惠任务

## 4. Mechanic（机械师）—— 91 个任务（全商人最多）

化工厂工程师出身的地下枪匠，说话像电路图。任务网两大支柱：**Gunsmith 改枪流水线**（数量最多的子系列）与**信号/灯塔接触线**（通往 Lightkeeper 的剧情主干）；另外还握着两条枢纽链：Introduction（解锁 Jaeger）与 1.0 的「武装侦察」Hub。

### 4.1 Gunsmith 改枪线（枪匠 + 枪匠大师，全期）
从"枪匠 - AKS-74U"这类单枪改装（buildWeapon：把指定武器改到人机/精度阈值）起步，L26 后出现 M4A1/AKM/AS VAL 等高级单，L40 进入 **枪匠大师 1-13** 连锁，终点是 **同好俱乐部**（L45，9 目标）——Mechanic 把改枪做成了一门"手艺宗教"。
- 代表任务：枪匠 - AKS-74U / HK MP5 / MP-133 → 枪匠 - M4A1 / AKM → 枪匠大师 - 1 ~ 13 → 同好俱乐部
- 目标类型：buildWeapon（属性阈值改装）+ 少量交配件
- 写模版价值：这是全游戏最清晰的"技能线"模板——单点教学 → 品类扩展 → 大师连锁 → 社交收束

### 4.2 灯塔接触线 / Network Provider（仙女棒线，0 级起连串到中期）
Mechanic 的大叙事：塔科夫通讯网被掐断，他要你**恢复与外界的信号**——网络供应商 - 1/-2（定位信号源）→ 试探 - 1~3 → 灯塔之匙 → 咚咚咚 → 邂逅 → 破镜重圆 系列（9 段长链）。这条链一边铺垫"谁在灯塔那边"，一边是 Lightkeeper「情报之源」的接入口（咚咚咚 直接成为其前置）。
- 代表任务：网络供应商 - 1/-2、试探 - 1~3、灯塔之匙、咚咚咚、邂逅、破镜重圆
- 目标类型：mark（放无线电信标）、visit（信号点）、findQuestItem（天线/钥匙）、上交电子件

### 4.3 Introduction 解锁线（早期）
「介绍」（Introduction，L0-5 档）：Mechanic 让你去工厂放标记、再带信进 Woods——完成后 **Jaeger 商人解锁**。全游戏最重要的"解锁节点"之一。
- 目标类型：mark + 放置信件 + 撤离；写完这条链再谈 Jaeger（§6）

### 4.4 化工厂/地下秘密线（前期至中期）
化工厂的秘密（Polikhim，注意：实际发生在 **Factory 图**而非 Customs，0.16 快照坐标可证）、不良嗜好、捕鼠计划、你被盯上了、挖矿 1-2、稳定信号、信号 - 3/-4——"废工厂里有人搞鬼"的调查+清剿戏。
- 代表任务：化工厂的秘密、捕鼠计划、你被盯上了、挖矿 - 1/-2、信号 - 3/-4
- 目标类型：放置工具/炸药、击杀、上交电子设备

### 4.5 1.0 核心枢纽线（26 级 Hub）
影子雇员 → 大海捞针 → 暗藏玄机 → **武装侦察** → 检验假说：Mechanic 侧的一条新主线，而中间的「武装侦察」是全任务网最大的聚合点之一——它同时是 Skier 绝对威信、Peacekeeper 机密情报、Therapist 这带子糟透了、Ragman 清空外围的前置，并最终汇入 Lightkeeper「守望者箴言」（须六大商人各一任务）。
- 代表任务：影子雇员、大海捞针、暗藏玄机、武装侦察、检验假说
- 写模版价值：完美的"主线 Hub + 多商人扇出"结构范例

## 5. Jaeger（猎人）—— 64 个任务

住在 Woods 的老猎人，仇视文明、信奉荒野。他的任务网是三套大系列 + 一堆野外杂务，主题高度统一：**一切问题都可以用"杀掉它"解决，但必须按他的规矩杀**。

### 5.1 The Huntsman Path 猎人之路（悬赏系列，0-55 级全域）
二十来支独立悬赏，每支一个"猎物"：森林管理员（Woods 相关）、杀戮森林、愤怒守望者、工厂头目（Factory Boss）、坏警察、管理者、支配者、解放、流浪汉、大动作、蒸发密令、控制、无情杀手（55 级收尾）……对应不同 Boss/精英的击杀条款，是最典型的"猎人笔记"结构。
- 代表任务：猎人之路 - 森林管理员、猎人之路 - 工厂头目、猎人之路 - 愤怒守望者、猎人之路 - 无情杀手（英文 The Huntsman Path - *）
- 目标类型：击杀（Boss/指定 mob、着装/武器限定）、放置诱饵或陷阱

### 5.2 The Survivalist Path 生存者之路（连锁求生线，9-33 级）
一条**严格串联**的生存挑战链：省吃俭用 → Zhivchik → 危险零距离 → 受伤的野兽 → 硬汉 → 支配者 → 冷血 → 雕鸮 → 战地军医 → 瘾君子。每步一个自虐式条件（不穿甲杀 PMC、带伤状态撤离、脱水状态下存活等），是"境界修炼"型任务链的教科书。
- 代表任务：生存者之路 - 省吃俭用、生存者之路 - 危险零距离、生存者之路 - 硬汉、生存者之路 - 瘾君子
- 目标类型：带状态约束的击杀/生存（playerHealthEffect/enemyHealthEffect 判定）

### 5.3 The Tarkov Shooter 塔科夫神射手 1-7（17-33 级为主）
栓动步枪的浪漫：只用狙击枪在指定距离完成淘汰，逐部加难度（爆头、远距离、指定图）。塔科夫神射手 - 4 是 Fence「收藏家」五大前置之一。
- 目标类型：击杀（栓动/狙击距离/爆头限定）

### 5.4 荒野杂务与"猎人社交"（散布全期）
熟人、狩猎之旅、礼节性拜访、怀旧之情、美味香肠、鱼塘、储备、隐士、黑幕交易、屠宰场、流浪狗、幽闭恐惧症、别开枪！、妥善保管——野外物资收集 + 与"猎物/同行"打交道；直播 - 3~5 是承接 Mechanic 直播系列的转包。
- 代表任务：熟人、狩猎之旅、隐士、黑幕交易、屠宰场、流浪狗
- 目标类型：野外 findItem、击杀特定动物/敌人、上交猎物证明

## 6. Peacekeeper（维和人员）—— 51 个任务

驻塔科夫的 UN 维和部队军官，实际是 USEC 雇佣兵体系的中间人，用美元结算。任务主题：**以"维和"为名的脏活 + 西式装备/情报生意**。早期任务偏物资收集（给当地"友军"输血），中期起转向海岸线/灯塔的暗战（湿活），后期是"证明你够格当向导"的生存长跑。

### 6.1 人道/输血线（前期 0-12 级）
人道主义援助、燃料短缺、你渴望电力吗、破铜烂铁、武器流通、渔具、主钥匙、单程票、猎虎行动（Tigr Safari）——主题是"给陷在塔科夫的西方人/友军送物资、找装备"，美元结算的西式装备线就此展开。
- 代表任务：人道主义援助、燃料短缺、武器流通、渔具、主钥匙、猎虎行动
- 目标类型：上交物资/装备（giveItem）、findItem

### 6.2 疗养之旅 Spa Tour（12 级档，疗养院门路）
主钥匙/单程票 打开的海岸线疗养院线：疗养之旅 - 2、- 6——借着"去疗养院办事"的名义深入 Resort，是 Peacekeeper 早期重要的地图深耕任务。
- 目标类型：findQuestItem（疗养院贵重物）、击杀

### 6.3 情报与"脏活"线（前期末-中期）
TerraGroup 雇员、神秘货物（Cargo X）1-3、邪教、定向追踪、鹰眼、秘密消息——收集 TerraGroup/邪教情报；**湿活（Wet Job）1-6**（8-37 级）则是贯穿最久的击杀链：海岸线/灯塔区域的定向清除，每步换目标、换规矩。
- 代表任务：神秘货物 - 1~3、湿活 - 1 → -2 → -3 → -4 → -5 → -6、邪教
- 目标类型：击杀（指定 mob/Boss、区域限定）、findQuestItem（情报物）

### 6.4 无中生有 Revision 与终局生存线（19-37 级）
无中生有 - 塔科夫街区 / - 储备站 / - 灯塔（英文 Revision - *）三图深耕；后期 向导（The Guide，32 级）、样品（37 级，14 目标）、最烂的差事、导师——"活着走遍所有图"的终局证明。机密情报（L26）挂在武装侦察 Hub 后。
- 代表任务：无中生有 - 储备站、向导、样品、最烂的差事、导师
- 目标类型：生存+撤离（extract/experience 判定）、击杀精英、上交样品

## 7. Ragman（破布商人）—— 58 个任务

ULTRA 商场里捡破烂起家的服装商。任务主题三件套：**收布缝衣、经营商场、跑运输**；人物弧线从"垃圾佬"一路爬到 42 级的"看不见的大手"（地下商会头目）。

### 7.1 服装/缝纫线（前期至后期）
临行密密缝（Sew it Good）1-4 → 人靠衣装 1-2 → 纺织业（Textile）1-2：从缝枪套到做高级服装的"手艺成长线"。临行密密缝 - 2 是 Fence「收藏家」前置之一。
- 代表任务：临行密密缝 - 1~4、人靠衣装 - 1/-2、纺织业 - 1/-2
- 目标类型：上交布料/缝纫材料/服装成品

### 7.2 ULTRA 商场经营线（前期）
Make ULTRA Great Again、垃圾佬、库存清单、大甩卖、火线速递、燃油危机、盛装杀戮（Dressed to Kill）——把 ULTRA 商场当自家店面打理：清货、供电、赶人。
- 代表任务：Make ULTRA Great Again、垃圾佬、大甩卖、盛装杀戮
- 目标类型：击杀（商场清场）、上交商品、访问区域

### 7.3 物流/运输合作线（前期-中期）
成功的关键、暗度陈仓、风流倜傥、财务总监、微型客车、生意至上、此路是我开！——"运货"主题，与 BTR 司机网深度咬合：稳定业务 / 再次延误 是 BTR「电池换新」「投石问路」的直接入口。
- 代表任务：成功的关键、暗度陈仓、此路是我开！、稳定业务、再次延误
- 目标类型：找货车/钥匙、护送、上交货物

### 7.4 商会头目线（1.0 新增 + 42 级终局）
新起点（同名四连，25/30/35/40 级四档）——战后重建主题的连续扩张；42 级终局组：看不见的大手 → 经济流动 → 特殊提议 → 实战考验 → 旧情难却，把 Ragman 推到"地下经济操盘手"的位置。清空外围（L26）挂在武装侦察 Hub 后。
- 代表任务：新起点（四档）、看不见的大手、经济流动、特殊提议、实战考验、旧情难却
- 目标类型：清场、交"经营物资"、击杀竞对

## 8. Fence（栅栏）—— 16 个任务

没有脸的中间商，全图 Scav 的"幕后老板"。任务主题极特别：**karma 与救赎**。他不给你活干，他给你"做人"的考试。

### 8.1 karma/信任线（前期）
建立联系 → 陌路相交（Friend Among Strangers）→ 免疫力 → 小本生意 - 1 → - 2 → - 3：靠"和 Scav 和平共处/合作撤离/不背刺"积累信任，小本生意 - 1 有 18 个目标（全游戏最大杂烩任务之一）。
- 目标类型：行为约束类（不攻击 Scav 的击杀、合作撤离、上交"见面礼"）

### 8.2 亡羊补牢线（赎罪五选）
亡羊补牢 - 信任 / - 赌注 / - 酒保 / - 收藏 / - Wergild（5 支并列，英文名直译"弥补"）：主题是"为过去的恶行还债"，玩家自选赎罪方式。
- 目标类型：上交/收集 + 特定行为判定

### 8.3 终极收藏与抉择（终局，42-50 级）
这是什么梗？→（前置五商人任务：天神射手/临行密密缝 - 2/邮递员派特 - 2/化学品 - 3/塔科夫神射手 - 4）→ **收藏家**（44 目标全图收集）→ **抉择**（50 级、433,333 经验、前置惩罚者 - 6）：全游戏经验最高的单个任务，Fence 给你一道"立场选择题"作结。
- 目标类型：全图 findItem 收集、击杀/对话收尾
- 剧情意义：收藏家 + 抉择 = 全任务网的"毕业考"，适合作为小说终章节点

## 9. Lightkeeper（灯塔看守人）—— 14 个任务

躲在海岛上的神秘"网络之神"，只通过无线电与世界对话。任务线很短但密度极高：一段 **十步岛内主线** + 外围跑腿 + 一个 26 级聚合任务。

### 9.1 岛内十步主线（情报与棋局）
情报之源 → 失踪的线人 → 抢夺先机 → 归还人情 → 以牙还牙 → 挑衅 → 按图索骥 → 观察员 → 大显身手 → 大都会之谜：Lightkeeper 的"仙女棒"网络叙事——先证明你能听懂他的暗语，再逐步替他对抗"大都会"（某外部势力）。
- 入口：情报之源 须 Mechanic「咚咚咚」（即先走完 §4.2 灯塔接触线）
- 目标类型：放置/取回无线电物、击杀指定目标、观察指定点

### 9.2 外围跑腿（与 BTR 网咬合）
简单副业（须 BTR 现世报）、外部订单（须 BTR 必然回应）——Lightkeeper 借 BTR 运输网往大陆递东西。
- 目标类型：取货/送货（跨图往返）

### 9.3 守望者箴言（26 级聚合 Hub）
全游戏最重的多商人聚合任务：须 BTR 感官分析 - 2、Mechanic 检验假说、Ragman 清空外围、Peacekeeper 机密情报、Skier 绝对威信、Therapist 这带子糟透了——六大商人后期各交一个"投名状"，才配听 Lightkeeper 的"箴言"。
- 剧情意义：1.0 把全商人主线收束到 Lightkeeper 的"新世界秩序"叙事上
- 天降大礼 [PVP ZONE]（35 级）是其 PVP 侧延长

## 10. BTR 司机 —— 19 个任务

开着装甲运兵车在森林/街区/码头跑运输的"车轮商人"，戏份全在 1.0 的 **破冰船（Boreas 线）**：四条支线分别解决破冰船出航所需的**人、电、防空、物资**，最后汇合成「独立的代价」。

### 10.1 罗曼救援线（救科学家）
坚持到底 → 拯救大兵罗曼 → 苦涩的胜利 → 宿醉：从"找到失联的罗曼"到"把他活着带出来"，中间夹一场苦涩的胜利（10 目标大任务）与宿醉（战后一杯）。
- 目标类型：找人/救人（findQuestItem+击杀）、护送、撤离

### 10.2 风火轮运输线（跑车/货车）
货运延误 - 1（Prapor 前置）→ 风火轮 → 风火轮 - 再次出发 → 必然回应：BTR 的"本职"——运货、修车、被劫、再运；必然回应 继续通向 Lightkeeper「外部订单」。
- 目标类型：放置/取回货物、击杀劫匪、护送

### 10.3 电池/防空线（装备破冰船）
横插一杠（Prapor）/ 稳定业务（Ragman）双入口 → 电池换新 → 对空遮断 → 反将一军：给破冰船换电池、打掉天上的眼睛——军事准备主题。
- 目标类型：找电池/防空件、击杀

### 10.4 以物易物与接驳线
现世报 → 奠定基石 → 自然交换 → 再次延误（Ragman，另须必然回应）→ 投石问路：四条支线的"后勤底座"，用零件换人情、用情报换路线。
- 汇合点：独立的代价（须 电池换新 + 反将一军，即 §10.3 贯通后）——BTR 线收束，通往破冰船主场
- 独立任务：货运延误 - 2（须 Mechanic 一臂之力）、感官分析 - 2（接 Ragman 感官分析 - 1，通向守望者箴言）
- 目标类型：上交零件/物资、击杀、护送混合

## 12. 经典跨商人任务链（写链模板库）

任务网的"血管"是这几条横跨商人的接力链——写小说需要"多方角力"桥段、写 mod 需要"多商人互锁前置"时直接抄结构：

### 12.1 Introduction（介绍）→ 解锁 Jaeger
Mechanic「介绍」完成即解锁 Jaeger。结构=单商人"引荐"单节点，是任务网里最干净的**商人解锁模板**（后续可仿：Ragman 引荐 Ref、Mechanic 引荐 Lightkeeper 等）。
- 目标：工厂放标记 → Woods 放信 → 撤离（mark + plant + extract）

### 12.2 Chemical 系列（化学品 1-4，Skier 中心）
Skier 化学品 1-4 完成后一扇三：大客户（Prapor）、出于好奇（Therapist）、收买人心（Skier 自身），另作「收藏家」前置。结构=**罪案调查主线 → 多方买家抢线**。
- 写模版价值：一个"物证"（化学品）串起三个商人诉求，玩家必须选边/排序

### 12.3 口干舌燥（Thirsty）三商人接力
Jaeger 猎犬行动 ↔ Skier 养家糊口/送货服务 ↔ Therapist 往日回响/秘密配方（L9 档）：同一主题（配方/饮品）三段式接力——猎人找料、走私者运货、医生验方。
- 结构：A 找原料 → B 运输 → C 交付成品，天然的三幕式任务链

### 12.4 往昔时光环（Prapor 发起，四商人接力）
Prapor 往昔时光 - 1 → Therapist 质量标准 → Mechanic 航空包裹 → Prapor 往昔时光 - 2 → Skier 高光时刻 → Prapor 忠实观众 → Skier 严词指控 → Mechanic 镜头就位，开拍！：L12-17 档的"回忆/记录"群像链，前置环环相扣且回环（Prapor → Therapist → Mechanic → Prapor → Skier → Prapor → Skier → Mechanic）。
- 写模版价值：**环形前置**（A→B→C→D→A 的闭合信任圈）比线性链更有"江湖"味

### 12.5 直播系列（Mechanic → Jaeger 转包）
直播 - 1/-2（Mechanic）→ 直播 - 3/-4/-5（Jaeger）：同一题材在不同商人间的"转包"——上游出设备、下游出场地。

### 12.6 武装侦察 Hub（1.0 主线聚合）
Mechanic 影子雇员 → 大海捞针 → 暗藏玄机 → 武装侦察 → 检验假说；武装侦察 单向扇出六商人（Skier/Peacekeeper/Therapist/Ragman 各一 + BTR 感官分析 + 汇入 Lightkeeper 守望者箴言）。**Hub-and-spoke 聚合**的最佳范例。

### 12.7 收藏家 → 抉择（全商人毕业考）
收藏家 前置跨五商人（Mechanic 天神射手 / Ragman 临行密密缝 - 2 / Therapist 邮递员派特 - 2 / Skier 化学品 - 3 / Jaeger 塔科夫神射手 - 4），完成后接 Fence「抉择」（另须 Prapor 惩罚者 - 6）。**终局聚合**结构：让每条主线的终点都成为终极任务的一把钥匙。

### 12.8 Friend from Norvinsk（1.0 新线，快照核查注记）
live 1.0 宣传的"诺文斯克朋友圈"大线，在 tarkov.dev 2026-09-02 快照中**没有独立条目**；相关内容以碎片任务呈现：西方来客（Friend From the West）、陌路相交（Friend Among Strangers）、缔结友谊（Forge a Friendship）、识时务者为俊杰（Choose Your Friends Wisely）。引用时以这几支为准，勿声称存在"Friend from Norvinsk"单任务。

## 13. 对写小说/写 mod 的用途说明

- **角色成长弧线素材**：每位商人的任务网 = 一种"人生剧本"——
  - 复仇弧：Prapor 惩罚者 1-6（由恨到清算）
  - 救赎弧：Fence 亡羊补牢 → 抉择（由恶到择善）
  - 野心弧：Skier 化学品 → L50 生意组（由脏到白）
  - 修行弧：Jaeger 生存者之路（由蛮到道）
  - 情报弧：Therapist 医疗隐私 → 街区之下（由医到谍）
  写角色时选一弧线，任务名/目标类型即可当"章节标题"。
- **mod 任务链模板**：上文标注"写模版价值"的结构可直接复用——商人解锁单点（§12.1）、物证扇出（§12.2）、三幕接力（§12.3）、环形信任（§12.4）、Hub-and-spoke 聚合（§12.6）、终局毕业考（§12.7）。SPT 侧实现参考 `curated/recipes/06-add-custom-quest.md`（前置字段 taskRequirements 对应 live 的 taskRequirements，condition 的 id 与 live objective id 1:1）。
- **选商人 = 选立场**：同一目标（如杀某 Boss）在 Jaeger（悬赏）、Prapor（惩罚）、Peacekeeper（脏活）手里叙事完全不同——写冲突时让两个商人对同一目标给出对立前置，是最省力的戏剧引擎。
