# 塔科夫时间线

> 状态：2026-08-16 提炼 | 版本标签：[通用]
> 来源：Fandom Wiki（Norvinsk region / 各地图页）、Wikipedia、NamuWiki（Contract Wars）、eftarkov.com（删档历史）

## 一、世界时间线（世界观内）

| 时间 | 事件 |
|------|------|
| ~2004 | USEC 与 TerraGroup 国际控股建立雇佣关系，逐步成为其私人军队 |
| 2009 | 化工厂 16 号土地被非法出售给 TerraGroup 研究所（工厂地图前身） |
| 2015-2018 | Norvinsk SEZ 经济繁荣期；TerraGroup 及多家跨国企业入驻，暗中进行非法研究 |
| 2017-2018 | 俄罗斯政府对 USEC/TerraGroup 活动疑心加重；BEAR 受秘密法令组建，前苏特种部队军官集结 |
| 2018-2019 | TerraGroup 丑闻爆发：侦探发现隐藏合同与通讯记录；政治对峙持续约六个月 |
| 2019-2020 | 冲突升级为武装冲突：UNTAR 维和部队 + MVD 内卫部队 + USEC/BEAR 两家 PMC 卷入（Contract Wars 时期）；USEC 在灯塔（达利尼角）建立进入塔科夫的主要入口 |
| ~2021 | Contract Wars 结束/阶段转换：塔科夫区域被最终封锁，PMC 部分人员滞留；Scav 帮派开始控制城区 |
| 封锁后 | 游戏主线开始：玩家扮演滞留的 BEAR/USEC 雇佣兵，在封锁区执行任务、设法逃离（游戏时间跨度 2015-2026） |

> 注：官方对具体年份刻意模糊，社区共识为"冲突持续数年、封锁长期化"。游戏中没有明确"今天几号"，但删档赛季与主线章节推进构成玩家的时间感。

## 二、1.0 主线剧情顺序（游戏内章节）

九章主线 + 终局分支（详见 `07-story-chapters.md`）：

1. 塔科夫之旅（Tour）→ 2. 陨落星辰（Falling Skies）→ 3. Batya → 4. 意外证人（Accidental Witness）→ 5. 他们已经来了（They've Arrived）→ 6. 神秘蓝焰（Mysterious Blue Flame）→ 7. 探秘"迷宫"（The Labyrinth）→ 8. 无名者（The Nameless Ones）→ 9. Boreas → 终局：门票（The Ticket）四结局

- 章节解锁依赖商人任务与藏身处等级（如情报中心 1/3 级、Fence 好感 2.0/4.0）。
- 地图直接进入权限随章节推进开放（Tour 解锁前只能靠转场 Transit 进入大多数地图）。
- 破冰船地图进入需先完成 Boreas 线并解锁 BTR 司机任务线。

## 对 SPT 环境的意义

- SPT（4.1）基于 1.0 时代客户端：**主线章节系统、转生（Prestige）、赛季服/BattlePass 机制均已包含**，mod 开发可围绕这些系统做文章。
- 删档表可用于整合包发版节奏参照：SPT 单机无官方删档，是否"删档"由玩家/整合包自行决定（SPT 支持手动 wipe profile）。
- 剧情章节的解锁逻辑（商人好感、藏身处等级、任务前置链）是任务类 mod 设计前置条件时的世界观模板。
