# Modding Standard 的形态：证据分级 + 工程化落地

SPT mod 生态缺乏统一规范（297 个近期语料的 Top 5 不规范点见 `.scratch/modding-standard/corpus-survey.md`）。裁决：规范做成"工程化默认值"——分级规则集（MUST/SHOULD/MAY + 证据分级 + 稳定 Rule ID）为载体，落地靠模板/技能优先、检查器二期；不做"唯一正确写法"的教条，也不做纯文档风格指南。版本策略：单规则集 + 规则级版本标签（4.1.5/5.0），不做两份并行规范。理由：语料证据显示"社区惯例"与"官方机制"存在系统性冲突（如 `ModDependencies` 硬语义在 392 个语料目录中零使用），分级 + 证据制是唯一能同时承载"正确性"与"惯例现实"的形态；单集合避免双份维护漂移。
