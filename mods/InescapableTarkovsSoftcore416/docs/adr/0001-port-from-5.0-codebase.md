# ADR-0001：SPT 4.1.6 版从 5.0 实现移植，而非从源 TS 重写

- 状态：已接受（2026-10-12）
- 决策人：Overseer（用户）

## 背景

同一产品「Inescapable Tarkov's Softcore」已有一条 SPT 5.0 线的完整 C# 实现（六组转录、内嵌数据表、默认值差异表、单测、缺陷修复成果）。现需要 SPT 4.1.6 版并部署至 Norvinsk_Forever 实例。4.1.6 与 5.0 的服务端属同一 C# 重写架构（SPTarkov.* 命名空间、IModMetadata + IOnLoad、user/mods DLL 布局、无 package.json）；4.1.6 API 兼容矩阵核验显示骨架零改动，差异集中在数据模型可空性与少量成员类型。

## 决策

以 5.0 实现为移植源：复用其代码转录、数据表、默认值差异表与测试套件，仅做「4.1.6 适配」（可空性修正、`SptVersion` 区间、运行时引用指向）与部署适配；源 TS 仅作语义参照。两目标线平行维护、互不同步。

## 备选方案

1. 从源 TS 为 4.1.6 重写 —— 否决：转录与数据工作已在上一条线完成，重做无收益且有引入偏差风险。
2. 等待源六件套出现 4.1.6 官方版本 —— 否决：产品目标是单一自包含 mod 与统一中文配置，多 mod 共存不符合目标。

## 后果

- 正面：移植工作面收敛为 9 处可空性修正 + 3 项工程/元数据改写（已逐项核验）；默认值与缺陷修复成果随移植继承；两线行为可通过同一差异表对照。
- 负面：4.1.6 数据形态差异（Collector 的 136 条前置、数据缺口条目）需按目标线数据单独裁决与登记；两线代码不自动同步，后续修复需按需回搬。
