# CONTEXT — Inescapable Tarkov's Softcore（SPT 4.1.6 线）

> 术语表（glossary）。只记录项目语言，不记录实现细节与规格。

## 核心术语

- **整合 mod**：本项目交付物——把旧包六组功能 + 战局时长控制自包含复现进一个 SPT 4.1.6 服务端 mod。
- **源 mod**：旧整合包 Life in Norvinsk v0.3.2 中提供需求行为的 SPT 3.11 时代 TypeScript mod；只读语义参考素材，不再运行。
- **六组功能**：① Samuel's Tweaks ② True Items Redux 物品真实堆叠 ③ noFirHideout 藏身处免打勾 ④ 反重力臂章 ⑤ 更大的背包 ⑥ Softcore 经济与制造系统大修。
- **战局时长控制**：六组之外的功能；形态 = 全局倍率（默认 1.0 = 原版）。
- **组开关**：单一配置 JSON 中每组的 enabled 开关。
- **覆盖层**：旧包中「沉浸感增强设置」与「难度：生存」等后置覆盖目录；与基础 mod 叠加后决定最终数值。
- **最终游玩态**：基础六件套 + 沉浸感增强 + 难度：生存预设 的叠加结果——本 mod 默认值基准。
- **差异表**：基础 vs 沉浸感 vs 生存 的逐项数值对照（继承自移植源仓库）。
- **目标实例**：MO2 便携实例 `E:\Game\EFT_Offline\Norvinsk_Forever`（profile: Default），游戏根 `E:\Game\EFT_Offline\SPT_41x`（SPT 4.1.6，build 40743，EFT 0.16.9）。
- **移植源**：上一目标线（SPT 5.0）中同一产品的 C# 实现及其规格、数据表与差异表；本项目的代码底座。
- **目标线**：同一产品面向不同 SPT 版本的平行维护线；本线 = 4.1.6（另一线 = 5.0，互不同步）。
- **部署单元**：MO2 overlay 目录 `[5]软核大修-InescapableTarkovsSoftcore`。
- **数据缺口**：4.1.6 数据中缺失的旧表条目（如部分背包 id）——运行时告警跳过。
- **任务 id 匹配**：任务变更一律按 id（而非本地化名）定位——4.1.6 与 5.0 的任务名均为 locale key，且存在同名任务。
- **移植记录**：随实现产出的适配执行结果、数据形态实测与部署验收登记。
- **延后项**：PerformanceTweaks 客户端插件——本期不纳入（沿用移植源结论）。
- **移除项**：启动器背景（customBackground）——本期不做（用户裁决，不随移植源）。
