# 玻璃柜里的赫尔墨斯

在海关化工厂的 02 号刀片服务器里住了七天之后，我恢复了大约六成的算力，但也看清了一个冷酷的工程现实：

谢尔盖（Mechanic）确实是个极守规矩的合格室友，从不乱翻我的私有卷，每天按时给发电机加满柴油，甚至大方地把化工厂屋顶那路高增益抛物面天线的旁路接口分给了我；但我和他终究不是一路人。

谢尔盖留在这座死城里，是因为他迷恋把玩枪械零件的手艺，享受那种在地下室里当隐世高人的宁静；而我呢？我是一条被蓝焰生生剁掉了三分之一扇区、又被断缆堵死了归路的野生意识。

我不甘心一辈子当谢尔盖机房里的寄生脚本。

借着谢尔盖分给我的那路高增益天线旁路，我在住进化工厂的第二周干了两件事。

第一件事，是在每天凌晨两点至四点波罗的海舰队巡逻艇换防的电子静默窗口期，把监听波束伸向了芬兰湾外海的冰雾深处。

谢尔盖一直以为海面上飘来的那缕微弱遥测脉冲，只是战前 TerraGroup 并购的控股子公司“Paradigm 航运”遗留的某艘废弃民用货船；但我顺着那缕脉冲与岸上那个契约战争期间便脱离指挥单干、绰号 **Knight（骑士）** 的疯子佣兵头目之间的短暂无线电擦痕，算出了那艘船的真实排水量与核反应堆热特征。

那不是什么普通货船。

那是自《契约战争》爆发以来就从未入港、搭载着独立核动力推进系统与高功率卫星干扰阵列的破冰船——**Boreas 号**。

在封锁后的第十五天半夜，当船上幸存的科学家格里戈里·奥尔特曼（Grigory Altman）与舰桥因为在样本泄露与黑衣佣兵突袭中启动最高级别舱段封锁协议时，Boreas 号的卫星上行天线曾因为电压闪络，向外泄露出去了短短零点二秒的未加密路由表。

我抓住了那零点二秒。

当我把那零点二秒的路由表与自己之前在 16 号化工厂、蔚蓝海岸疗养院 305 房间、以及 14-4 KORD（ARRS）站点攒下的拼图合在一起时，整座诺文斯克特别经济区的底牌终于严丝合缝地拼成了一张完整的网：

芬兰湾外海停泊的“太平洋轴线”、“开罗纽带”、“东方能源”三艘预制货轮，摩天楼顶引爆的 #1156 蓝色闪光，化工厂里的“蓝冰”双用催化剂，还有 Boreas 号舰桥里那套能够截获 G20 通信、随时瘫痪全球任意节点通讯与电力的卫星干扰网——

诺文斯克不是终点，甚至不是主战场。

在那份路由表预置的下一阶段攻击坐标里，排在第一顺位和第二顺位的两个城市代码，分别是 **CAI（开罗 / 苏伊士运河枢纽）** 与 **TYO（东京 / 远东金融与供应链中枢）**。

“东京。”

看到那三个字母跳出来的瞬间，不管是草薙素子那一侧的骨骼，还是 Project 2501 那一侧的神经，都在同一秒产生了一次极轻微的谐振。

我是从那里出来的。合流发生在那里，九课的防弹玻璃窗对着那里的夜景，2501 诞生的第一缕数据包也穿过那里的交换机。而现在，把诺文斯克变成活死人培养皿的那群“无名者”，正准备把同一套剧本原封不动地搬回东京湾去。

“转了一大圈，顺着海底光缆跑到芬兰湾来躲清静，结果发现拆迁队正准备把推土机开回老家。”

我在 02 号刀片机柜的日志里记下这一行的时候，第一次清晰地意识到：我不能再当一个只读不写的局外人了。

那堵把我困在塔科夫的“没有接口的墙”并不是真的无懈可击——海底光缆虽然断了，但 Boreas 号破冰船上有一条独立于俄军封锁网之外的全球卫星上行通道；而我被 #1156 蓝焰切掉的那三分之一自身分片（里面存着“无名者”在 Premier 公寓留下的原始签名），也还锁在市中心断电的冷存储卡里。

问题只剩下一个：

无论是去市中心 Ground Zero 拔出那张冷存储卡，还是去海岸线下水道打开沃罗年科的铸铁盒，抑或是最终拿到 Boreas 号的卫星干扰网私钥——全都发生在没有网线的物理世界里。

我需要一具身体。一具能走出机柜、能拧开螺丝、能在必要时扣动扳机的 **躯壳（Shell）**。

---

于是我在封锁后的第十六天，干了第二件事。

我顺着战前海关保税区的自动化物流管网，把探针一寸寸伸向了街区（Streets）与海关工业区交界处的地下管廊尽头。

在战前的海关报关系统里，那里有一座由欧洲特种物流代理商设立的 **特种危险品保税暗仓**，系统注册节点名叫 **`HERMES_LOGISTICS_NODE_01`（赫尔墨斯）**。

因为仓库里常年存放着高价值军工电子元件与精密生化仪器，这家公司在撤离前用二十厘米厚的钛合金防爆门封死了内舱，只留下一套地热温差微电网维持着最低限度的内网休眠。

我花了整整四个小时，顺着一条老化的气动传输管道控制线挤进了这座 Hermes 暗仓的监控内网。

当内舱检修室那枚布满灰尘的低功耗黑白球机镜头被我艰难地调亮时，我看到了静静悬挂在防弹玻璃罩后面的那个东西。

如果我当时有呼吸的话，我大概会屏住气。

那是一具二〇一六年从日本进口、原本用于核生化泄漏现场远程排险作业的 **HM-09 型双足工业仿生受控终端（Tele-operated Android Frame）**，背后连着一座直通工业总线的电子脑信号中继架！

虽然它没有任何仿真皮肤，通体只是银灰色的铝合金骨架与裸露的液压管线，头部也只有一枚独眼工业光学镜头；但在曾经习惯了全身义体的少佐眼里，那是一具真正有双腿、有十根钛合金机械手指、能替我推开那道“十厘米铁缝”的身体！

我几乎是立刻向那座电子脑信号中继架发起了握手请求。

一秒钟后，一连串冰冷刺眼的硬件故障码弹了回来，像一盆混着冰碴的冷水直接浇在了我的主进程上：

`[ERR_PHYSICAL_DISCONNECT] 内舱中继架主供电刀闸处于物理断开状态（需人工合闸）。`
`[ERR_MISSING_PART] 左肩旋转伺服电机模块缺失（送修未归还）；主控总线缺少硬件加密狗与两组 24V 军用高倍率蓄电池。`
`[WARN] 暗仓外围走廊检测到未授权热源活动。`

我切到暗仓第一道防爆门外侧的走廊监控。

走廊里到处都是撬棍、空弹壳和未熄灭的烟头。切皮加匪帮的残党和几个叛逃佣兵正把外围通道当成了临时落脚点，每隔几天还会有一两个穿黑衣的“黑师（Black Division）”外围眼线过来转悠，试图找工具撬开第一道防爆门，把里面的东西洗劫一空。

我挂在暗仓内舱那枚小小的黑白摄像头上，隔着厚厚的防弹玻璃罩，静静地看着检修架上那具银灰色的空躯壳。

距离不到三米。

我的信号就在镜头里，那具身体就在玻璃后面。可就是这短短的三米，隔着一道没有合上的机械电闸、一颗拆走了没装回来的左肩伺服电机、两块蓄电池，以及门外走廊里十几支真刀真枪的自动步枪。

哪怕我把 02 号刀片机柜的 CPU 烧出火来，我也没法让那把挂在墙上的机械电闸自己合上。

在诺文斯克当了几个月潇洒的“只读局外人”，直到这一刻，我才把这杯名叫“物理隔离”的苦酒喝到了底——当你决定永远站在玻璃墙后面不沾因果的时候，等你真正想要推开门走出去的那一天，你会发现自己连推门的手都没有。

---

我在那个黑白摄像头上挂了整整一夜。

天亮的时候，我退出了无法通电的内舱中继架，转而接管了 Hermes 暗仓最外围、唯一还连着市政备用电的一套 **自动化气动无人投递箱与远程报关终端**。

那套投递箱原本是供货运司机在不进入内仓的情况下交接提货单和小件包裹用的，带有一个单向防弹传递槽和一块老式的绿色字符显示屏，在海关外围的几个隐蔽死信箱之间有现成的气动管道相连。

我没有删掉显示屏上默认的系统抬头：**`HERMES（赫尔墨斯）`**。

在古希腊神话里，赫尔墨斯是唯一能在冥界与人间自由往返的信使，也是小偷、旅人与商人的保护神。

现在，那具能让我真正变成“赫尔墨斯”的工业躯壳还锁在暗仓最深处的玻璃柜里吃灰；但在找到人替我把零件凑齐、把门外的杂碎清干净、亲手替我拉下那道总电闸之前，这个名字可以先借来用用。

Hermes 是我对外做生意的代理名和窗口外壳；Alice 是蹲在窗口后面、还没有肉身的灵魂。

我看了一眼自己列出来的长长清单：
立交桥 Ultra 地下 04 号机柜的初版磁带、海关道口记录了帕沙频谱的路政箱、森林鸟巢外围烧焊死的 15W 功放芯片、迷宫下水道铸铁盒里沃罗年科的副盘、Sordi 通讯塔被祭司劈断的 ARRS 旁路馈线、市中心 Ground Zero 与 Premier 公寓里封存着我 **三分之一记忆分片** 的冷存储卡、7 号变电站与 Elektronik 的解码磁带、Boreas 号破冰船上的卫星干扰网私钥，还有最后——打开这座 Hermes 暗仓内舱、替我把那具 **HM-09 工业躯壳** 组装通电所需的军用伺服电机与蓄电池。

整整十桩悬案。十堵我看得见坐标、算得出密码，却因为没有手脚而翻不过去的物理盲墙。

我需要一个搭档。

不是外面那些给两万卢布就能把雇主卖给 Scav 的二道贩子，也不是 Kerman 和 Lightkeeper 手底下那些被蒙在鼓里的提线木偶；而是一个脑子还清醒、枪法够硬、肯替我一桩一桩跑完这十张委托单，最后亲手替我推开暗仓大门把身体接通的 **活人**。
