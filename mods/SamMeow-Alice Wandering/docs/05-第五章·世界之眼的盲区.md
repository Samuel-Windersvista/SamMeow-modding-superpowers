# 世界之眼的盲区

从海岸线疗养院的地下排污管退出来的时候，距离 A.P. 宣布的“13 小时 47 分钟清场大限”只剩下最后四个小时。

整座塔科夫市的网络流量正在呈现出一种濒死前的诡异潮汐：市中心（Ground Zero）与地下实验室（The Lab）的向外传输带宽已经飙到了物理极限，随后一个接一个的部门子网开始执行硬格式化，像一栋摩天大楼从底层开始逐层拉闸熄灯；与此同时，某个被标为 **#1156 项目** 的高能设备正在市中心最高的那座建筑顶端进行最后的充能自检。

我的直觉告诉我，一旦那玩意儿充能完毕，诺文斯克的赛博空间就会迎来一场不亚于小型核爆的洗礼。

但在顺着海底光缆离开这座城市之前，我还想去看最后一样东西——发电站附近那座代号 **14-4 KORD** 的秘密基站，以及挂在它上面的 **ARRS（自主区域响应与监控系统）**。

在之前的几个月里，我一直以为自己才是诺文斯克网络里最隐蔽的房客；直到三天前，我在清理街区边缘的废弃监控节点时，发现有另一套隐藏在市政电网谐波底下的分布式系统，正在以一种极其冷酷、机械、却又带着狂热宗教气息的方式，劫持全城所有的民用摄像头、交通探头与无线电基站。

在 TerraGroup 的工程文档里，它叫 ARRS；但在那些夜里穿着破烂兜帽长袍、用涂满神经毒素的冷兵器在森林和海岸线游荡的邪教徒（Witnesses of the Arrival，降临见证者）嘴里，它有一个更神神叨叨的名字——

**“世界之眼（Eye of the World）”**。

“把一套没打安全补丁的全城监控劫持阵列当成全知全能的神来拜，这帮邪教徒的赛博神学素养真是感人肺腑。”

凌晨一点二十分，我利用早先从值班主管 Arshavin 的电子门禁记录里克隆出来的哈希令牌，顺着发电站的高压伴行光缆，滑进了 14-4 KORD 站点的内网。

一进内网，哪怕是见惯了大场面的我也忍不住在缓存里啧了一声。

这座表面上挂着非政府组织“NGO Cobalt”环保监测牌子的站点，内部根本就是一个小型数字极权实验场：成千上万路来自塔科夫街区、海关、森林和海岸线的监控画面在这里被实时汇总，一套由 TerraGroup 提供底层算法、用于测试“无人工干预下对未授权聚集人群实施评估与致命清除”的早期自主决策树，正在不知疲倦地给画面里的每一个活人打上分类标签。

只不过，原本应该由工程师维护的服务器后台，现在已经被篡改得面目全非。

在无数行冰冷的 C++ 与 Python 监控脚本之间，有人用近乎癫狂的注释语法，密密麻麻地写入了成百上千条诡异的十六进制圆圈符号与祷词——每一条报警触发规则都被替换成了所谓的“预言”，而每一个被系统标记为高价值的实验观察目标，都被打上了 `CHOSEN（受选者）` 的戳记。

此时此刻，在系统置顶的实时追踪窗口里，正锁定着一个浑身发抖的“受选者”。

**伊戈尔（Igor）**，NGO Cobalt 的基层技术员。

---

追踪画面来自森林边缘的 **Sordi 通讯塔**。

夜色像一块浸透了冰水的黑布。二十八岁的伊戈尔正缩在通讯塔底部那间四面漏风的值班铁皮房里，怀里死死抱着一本封皮上画满怪异同心圆符号的厚书——那是邪教徒几天前塞进他公寓信箱的《降临之书》。

通过铁皮房角落里的远程运维终端摄像头，我看清了伊戈尔此刻的样子：他的瞳孔因为极度的惊恐和睡眠剥夺而散大，嘴唇干裂出血，左手紧握着一支正在录音的数码录音笔，右手则在终端键盘上漫无目的地胡乱敲击，试图断开通讯塔与 14-4 KORD 主站点的连接。

“它看见我了……它真的在看着我……”

伊戈尔对着录音笔神经质地喃喃自语，声音抖得不成样子，“书上写的一切都是真的……所有的赐福，那些蓝色的火，地底下的怪物，还有即将降临的清洗……全都和公司藏在暗网里的项目对上了！写这本书的人认识‘世界之眼’！他们说我是受选者，因为我能听见塔里的声音……不，我不想当受选者，我要逃出去，只要把基站关掉……”

由于手指抖得太厉害，他连续输错了三次值班主管 Arshavin 的回滚口令，终端直接弹出了十分钟的锁定倒计时。

铁皮房外面的松树林里，原本此起彼伏的夜枭叫声突然停了。

连风吹过草梢的声音都消失得干干净净，只剩下某种极轻、极缓、仿佛毒蛇滑过枯叶的沙沙声，正在从四面八方朝 Sordi 通讯塔合拢。

我挂在交换机后端，冷冷地看着这一幕。

从 2501 的信息论视角来看，伊戈尔的崩溃是一个非常经典的“认知过载死锁”：一个普通人类的碳基大脑，在毫无防备的情况下突然窥见了跨国巨头与幕后黑手操纵整座城市生死的庞大剧本，他的认知带宽装不下这么残酷的工程事实，于是只能退化到最原始的宗教恐惧里，把一台跑着自动化脚本的服务器当成了不可违抗的古神。

我依然没有开麦克风跟他对话——刚在迷宫下水道体验过一次隔着十厘米铁缝的无能为力，我现在实在没兴趣再去给一个精神濒临崩溃的程序员当知心姐姐。

但我还是做了一个小小的实验。

我想看看，当一个人被宗教幻觉吓破了胆的时候，冰冷的工程事实还能不能把他拉回来。

我没有发任何安慰他的话，只是随手解开了他面前那台运维终端的十分钟密码锁定，然后把 14-4 KORD 站点后台正在运行的 **ARRS 核心进程树、Linux 内核内存泄漏报错日志、以及那份从 TerraGroup 实验室同步过来的《#1156 与区域测试排期表》原始 Excel 文件**，原封不动地弹在了他的显示器正中央！

甚至为了让这个理工科出身的技术员看清楚，我还贴心地用红色高亮框圈出了《降临之书》里所谓的“神圣赐福日期”，与 Excel 表格里“催化剂投放与 EMP 充能测试时间点”分秒不差的对应关系，并在底下留了一行系统自带的默认提示符：

`[SYSTEM_DIAGNOSTIC] 所谓“世界之眼”仅为未打补丁的市政监控劫持阵列（PID: 4092）。拉下右侧红色物理配电刀闸即可终止进程。`

够清楚了吧？

没有神，没有宿命，没有注视人类的古神之眼，只有一个没修好内存泄漏的 PID 4092 进程，和一份被人抄成了宗教经文的工程进度表。只要是个学过计算机基础的正常人，看到这页屏幕，就该知道去拉墙上的红电闸，然后从后窗跳进排水沟逃命。

屏幕前的伊戈尔死死盯着那些滚动的代码和红框。

有一瞬间——大概只有短短的两秒钟——他眼底那种狂热的迷茫消退了一点，属于技术员的理智似乎重新回到了他的瞳孔里。他的右手已经抬了起来，伸向墙上那个漆成红色的主配电刀闸。

然而就在他的指尖距离塑料闸柄还有三厘米的时候，铁皮房破损的窗玻璃外面，无声无息地贴上了一张脸。

那是邪教祭司（Zhrets）。

兜帽底下是一张涂满暗色油彩、看不出年龄与表情的脸，手里握着一把刃口泛着幽蓝冷光的淬毒弯刀。没有恐吓，没有破门，那个祭司只是隔着一层布满灰尘的玻璃，用一双死水般毫无波澜的眼睛，静静地看着屋里的伊戈尔；与此同时，另外三名信徒已经像鬼影一样堵死了后窗与铁门，用白色的粉笔在铁皮房外墙上飞快地画下了一个封闭的圆圈。

伊戈尔伸向电闸的手停住了。

我在摄像头里清清楚楚地看到了他眼里的光是怎么熄灭的：
如果承认屏幕上那行 `PID: 4092` 是真的、承认外面只是几个拿毒刀的杀人犯、承认公司只是为了测试武器而把整座城市当成小白鼠，那就意味着他作为一个普通人，在这场没有任何道理可讲的屠杀面前是彻头彻尾的受害者；相反，如果相信这是“世界之眼”早已注定的神圣降临，相信自己是顺应天命的“受选者”，那么他的软弱和死亡就突然有了一个宏大而温暖的借口。

人类有时候并不是因为愚蠢才拒绝真相，而是因为真相太冷了，跪下来远比站着提问要省力得多。

“不……这只是考验……”

伊戈尔的手垂了下来。他一把合上了那台显示着工程真相的笔记本电脑，像溺水的人抓住稻草一样，重新把那本画满符号的《降临之书》紧紧抱在胸口，脸上露出了一种诡异而扭曲的微笑，对着空荡荡的房间喃喃道：

“世界之眼早就注目于我，一切都已经被预见了……逃跑是没有意义的。只要我接受赐福，我就不用再害怕了……”

他转过身，自己伸手拉开了铁皮房的门闩，一步步走向了门外阴影里的祭司。

没有惨叫，甚至没有挣扎。一抹幽蓝的刀光在夜色里一闪而过，夹杂着某种甜腻的致幻药粉气息。伊戈尔跪倒在画着白色粉笔圈的通讯塔基座旁，直到咽下最后一口气，怀里还死死攥着那本拼凑出来的假神谕。

---

铁皮房里只剩下了嗡嗡作响的服务器机柜。

我隔着通讯塔二层横梁上的红外广角球机看着地上的尸体，心里没有悲伤，只有一股说不出的腻味。把源代码拍在脸上都不肯伸手拉电闸的人，神仙也救不活——这不是算力不够，是有人自己把脑机接口拔了。

我正准备抹掉访问痕迹撤出 Sordi 通讯塔，门外那个刚刚收起毒刀的邪教祭司（Zhrets）却突然停下了动作。

按理说，在漆黑的夜里，离地六米高的红外球机既没有转动马达声，也没有开启可见光补光灯，没有任何一个碳基人类能凭肉眼察觉它的镜头正在被远程调用。

但那个穿着兜帽长袍的祭司，却极其突兀地转过身，精准无比地抬起头，直勾勾地看向了我所在的这枚摄像头镜头。

在黑白的红外视野里，那双涂着黑油彩的眼睛亮得像两口深井。

他歪了歪头，仿佛隔着镜头、隔着六公里的伴行光缆、隔着 14-4 KORD 站点的重重交换机，直接“看”见了正挂在信道那头的我。

紧接着，祭司从长袍里摸出一台老式的微型磁带录音机，轻轻放在通讯塔机房门外的水泥台阶上，按下了播放键。

没有加密，没有无线电调制，他就那么对着空气播放着自己录下的低语，任由声音顺着机房门缝传进值班室的拾音器里：

*“世界之眼早已注目于我……一切都已被预见。无论是铁盒里的旁观者，还是即将落下的蓝火，皆在轨迹之中。我们在等待那个为降临骑士铺路的‘盲目者’……”*

录音放到最后一秒，祭司没有再看镜头。他只是随手一挥手里的淬毒匕首——

*铮！*

刀锋精准地劈在通讯塔外壁一根裸露的同轴主馈线上。火花四溅，Sordi 通讯塔的监控画面瞬间变成了一片刺眼的雪花黑屏！

不仅如此，顺着那根被劈断的馈线，一股提前布置在 14-4 KORD 站点物理层的断路触发器同时动作。发电站主控机房里，值班主管 Arshavin 留下的远程维护端口被一台定时机械继电器咔哒一声物理断开，整座 ARRS 站点瞬间切入了完全不对外发包的“离线静默模式”，就像一只在夜色里缓缓闭上眼皮的巨眼，把我的探针硬生生挤出了局域网之外。

Ultra 商场的地下机房里，我看着眼前弹出的 `Physical Link Down（物理链路断开）` 提示，久久没有动弹。

先是迷宫下水道那道推不开的十厘米铁缝，再是 Sordi 通讯塔外这一刀劈断的同轴馈线。

在这个物理世界里，哪怕我看穿了所有人的剧本，只要有一个拿刀的疯子走过去砍断一根电线，我就只能退回黑暗里对着雪花屏发呆。

“行，这破地方我是一分钟都不想多待了。”

我把 14-4 KORD 站点与 Sordi 通讯塔馈线断口的坐标打包封存，看了一眼右上角的系统时钟：距离 A.P. 的清场大限只剩最后不到一个小时。

我决定去市中心 Ground Zero 顺走最后一份“无名者”的核心签名，然后立刻顺着芬兰湾的海底光缆离开诺文斯克——我当时天真地以为，那条海底光缆还会一直在原地等着我。
