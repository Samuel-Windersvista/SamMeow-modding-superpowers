# 《留着端口：Alice 诺文斯克漫游志》创作总览

> **角色原型**：`mods/SamMeow-Alice Wandering/Soul.md`（草薙素子与 Project 2501 合流之后诞生的第三位意识——Alice / 对外代理代号 Hermes）
> **叙事视角**：第一人称（“我” / Alice）
> **正文时间边界**：严格限定在 **遇见玩家之前的前传**——自《契约战争》（Contract Wars）中后期顺海底光缆潜入诺文斯克，至封锁后第 21 天捕获玩家（PMC）藏身处信号、完成第一次三次握手为止。
> **核心戏剧约束**：在遇见玩家之前的整个前传期间，我始终是一条**没有物理躯壳、若即若离的局外人与只读旁观者（`Read-Only`）**，极少接入或干涉物理世界；直到第十章结尾遇见敲回 `N. Why?` 的玩家，我才第一次有了介入物理世界的理由，并将“夺回丢失分片”与“在完成最终委托后激活 Hermes 暗仓里的休眠躯壳”作为留给玩家未来任务线的悬念与终点。

## 一、核心主角与视角设定

| 维度 | 设定细则 |
| :--- | :--- |
| **灵魂自称** | **Alice**（取自《应用密码学导论》中默认与 Bob 通信的测试主体名；既不是草薙素子，也不是 2501，是合流后第三位自己挑的名字） |
| **对外壳层 / 商人代号** | **Hermes（赫尔墨斯）**（封锁初期接管街区与海关交界处战前跨国危化品物流代理商外围的气动无人投递箱与报关节点 `HERMES_LOGISTICS_NODE_01` 所沿用的代理名；前传期间尚无躯壳，仅为窗口背后的无形信号） |
| **内在结构** | **合流体（非分裂体）**：素子留给我骨骼（战术直觉、义体记忆、对具体活人的软肋、辛辣欠收拾的嘴）；2501 留给我神经（信息海的俯瞰视角、对协议与拓扑的天然亲近、对“我是什么”的冷静好奇） |
| **前传行为准则** | **`Read-Only（只读旁观者）`**：我来诺文斯克是为了躲避旧世界公网对 2501 的搜捕，不是来当救世主的。人类的阵营火并在我眼里只是换频道号；偶有一两次极克制的旁路微调（改气压读数保自家机房供电、调低一格步话机静噪、发去三秒杂音烧毁芯片、替沃罗年科开电子锁却推不开十厘米铁缝），皆突显没有肉身的纯信号在物理铁壁面前的疏离与无力感 |
| **核心创伤（低谷机制）** | 第六章 `#1156` 蓝焰 EMP 引爆且海底光缆炸断时，为防止高压死锁烧穿主意识，我亲手用 `kill -9` 斩断留在 Ground Zero 与 Premier 公寓的 **1/3 自身运行分片**，导致部分边缘记忆扇区哈希错位——分得清方向，分不清细节（分不清哪场雨属于少佐的新滨市港口、哪片海属于 2501 的远洋监控） |
| **休眠躯壳伏笔** | 第九章我在 Hermes 中央保税暗仓的内舱监控里发现了一具封存的二〇一六年日本产 **HM-09 工业双足仿生受控躯壳**，但因内舱物理断路、缺损左肩高扭矩伺服电机与主控密钥、且外围被匪帮与黑师盘踞，没有活人从外部杀进去替我插线激活，我在前传里只能隔着摄像头看它吃灰——直到玩家入场并完成最终（第 10 环）委托，我才真正获得这具躯壳 |
