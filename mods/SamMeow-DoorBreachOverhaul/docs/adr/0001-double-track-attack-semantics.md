# 攻击语义双轨并行：锁血池（破门）与破坏模拟（毁伤）

合并版中，同一发命中同时喂给两套子系统：Backdoor Bandit 的锁区判定与锁血池决定"何时能开门"（保留原生踹门动画手感）；Door Overhaul 的破坏模拟决定"门被打成什么样"（弹孔/碎片/铰链/门闩/门板坠落）；两者互不阻塞。C4 引爆映射为最强的破坏输入（走完整破坏管线，不可破坏时回退强制开门）；上锁门不豁免——原 `locked: untouchable` 规则移除。本项目不统一两套耐久（锁血池与破坏细胞各自独立）。

## Considered Options

- 单轨统一：取消锁血池，开门改由门闩/铰链毁伤驱动。语义更整体，但"打锁开门"的直觉手感消失，且改动面最大。
- 血池吞并：毁伤与开门耦合在同一耐久、破坏模拟降级为纯视觉。牺牲 Door Overhaul 的精细破坏能力。

## Consequences

- 门存在两套独立耐久（锁血池 / 破坏细胞），调试面板需分别呈现；
- 统一命中分派点是后续调参（武器白名单、材质规则）的唯一入口。
