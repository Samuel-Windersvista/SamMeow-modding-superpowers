# 配置载体本地化：弃服务端下发，统一 BepInEx 本地配置

合并版将配置载体从上游的服务器下发（`/backdoorbandit/load`）改为本地 BepInEx 配置（F12 界面）。动因：该链路存在 null 崩溃隐患；单机场景不存在服务端权威需求；与 Door Overhaul 及整合包 `[15]` 配置叠层惯例一致；为实现"全部限制旋钮化"提供稳定载体。服务端组件（若保留）只负责物品体系，不再承载配置。

## Considered Options

- 保留服务端下发（仅修 null 分支）：与上游形态一致，但单机无收益，且配置不在玩家手里。

## Consequences

- 配置键面自行设计并需要版本化迁移策略；
- 上游后续的配置格式变化不再影响本项目。
