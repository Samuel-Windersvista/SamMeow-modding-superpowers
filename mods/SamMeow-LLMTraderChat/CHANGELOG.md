# Changelog

本文件记录本 mod 的版本与版本变化（规范：Modding Standard `STD-PKG-009`）。

- 格式：每版本一节 `## <version> - <YYYY-MM-DD>`，**最新在上**；节内分组为 新增 / 变更 / 修复 / 移除 / 已知限制。
- 版本号须与 `Directory.Build.props` 的 `<Version>`、以及 `deploy/meta.json` 的 `version` 三处一致。
- 与整合包级 release-changelog（`<project>/docs/release-changelog.md`）是**两个层级**，互不替代。

## 0.1.0 - 2026-10-14

首个可用版本。以下按里程碑记录 0.1.0 期间的能力演进（同一版本内多轮迭代，未再切版本号）。

### 新增

- **M1 骨架**（2026-10-14）：客户端解锁商人消息线程的输入闸门；服务端接住玩家发往商人的文字并回显，打通端到端链路。
- **M2 LLM 对话**（2026-10-14）：接入 OpenAI 兼容 LLM（默认云端 DeepSeek；可切换本地 Ollama 不出网）；按商人人格回复；一次性开场消息；`重置` 指令＝选择性清空（保留带附件的未领取消息）。
- **M3 知识检索**（2026-10-14）：关键词/子串检索后端（`IKnowledgeRetriever` 适配口，可替换）+ per-trader 知识文档注入 system prompt。
- **全商人接入**（2026-10-15）：19 位商人（12 原版 + 7 mod）全部可聊；mod 商人经纯配置接入（零代码），契约见 README。
- **动态态度**（2026-10-15）：按与该商人的好感度 / 忠诚等级 / 任务合作进展，语气在五档（敌意·冷淡·熟稔·信任·盟友）间变化；新增 `{{attitude}}` 段与 per-trader 档位文案覆写；不向玩家报出内部数值。
- **任务知识**（2026-10-16）：按态度档位披露该商人名下进行中委托的细节（None / Hint / Full 三档）；随包提供 15 位商人的任务手册（742 条委托）供检索；新增 `{{quests}}` 段与反编造硬约束。

### 变更

- 客户端标点修复：中文标点不再被输入框闸门拦截。
- LLM 参数：`maxTokens` 512 → 4096。

### 修复

- **全量回复退化为兜底话术**（玩家收到「（商人暂时联系不上，请稍后再试。）」）：定位为 `deepseek-flash` 属推理型模型，推理链吃满 `maxTokens` 预算时 API 返回 `finish_reason=length` + 空 `content`；按上条调整参数修复。
- **商人被问任务细节时自信编造**（实例：把「水瓶座行动」的地点说成「储备站底下的水处理区」，被玩家纠正后未承认不知道，反以「我知道但不细说」的姿态补圆）：补任务知识 + 反编造约束修复。
- 商人开场消息并发双发窗口：改为原子认领（at-most-once）。
- 知识/历史渲染超预算时静默截断：改为响亮告警（单条预算 + 总量预算）。

### 已知限制

- **静态任务手册走检索段，不受披露门控约束**：低好感商人在被直接追问时，仍可能引用手册给出准确细节（只是不再编造）。
- **推理型模型延迟**：单次回复引擎耗时约 3–13 s，叠加 2–6 s 回复延迟后，玩家可见等待约 10–18 s。
- **LLM 空响应诊断粒度**：客户端尚未解析 `finish_reason`，被 `max_tokens` 截断与「模型真没说话」在日志中区分度不足（已立工单 15，尚未实施）。
- 未启用的商人行为完全不受影响；与同类聊天 mod 的共存仅做代码侧分析，未做同装实测。
